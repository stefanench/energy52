# Sorting Visualizer

Sorting Visualizer is a desktop application written in Python that demonstrates how classic sorting algorithms rearrange data.

The program generates a random sequence of values, visualizes every comparison and swap, and animates the entire sorting process using a simple Tkinter interface.

## Features

- Bubble Sort visualization
- Selection Sort visualization
- Insertion Sort visualization
- Animated comparisons
- Random data generation
- Adjustable animation speed

## Run

```bash
python app.py
```
